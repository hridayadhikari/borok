# Borok

### A modern learning platform for Kokborok

**Borok** is a digital learning platform designed to make **Kokborok** more accessible through structured lessons, vocabulary, grammar, pronunciation, practice, and cultural context.

> I couldn't speak Kokborok, so I built a place to learn it.

**Live:** https://borok.vercel.app
**Story:** https://www.hridayadhikari.in/blog/i-couldnt-speak-kokborok-so-i-built-a-place-to-learn-it

---

## Why Borok?

Kokborok has a rich linguistic and cultural history, but modern, structured digital resources for learning the language are limited.

I grew up surrounded by Kokborok speakers but never properly learned the language myself. When I started looking for a simple and structured way to learn it, I found that much of the available material was scattered across books, documents, and reference resources.

So I decided to build the learning platform I wished existed.

Borok brings learning material together into an accessible and interactive experience.

## Features

### Structured Learning

* 28 guided lessons
* Progressive learning path
* Vocabulary
* Grammar
* Phrases
* Sentence construction
* Numbers
* Conversation

### Pronunciation

* Audio playback for vocabulary and phrases
* Pronunciation-focused learning
* Designed to support native-speaker recordings

> Current audio uses text-to-speech where available. General-purpose TTS systems may not pronounce some Kokborok words correctly.

### Practice and Revision

* Interactive practice
* Spaced Repetition System (SRS)
* Saved vocabulary
* Learning progress
* Daily learning streaks

### Dictionary

A searchable Kokborok vocabulary reference designed to make finding and revising words easier.

### Script and Grammar

* Roman-script learning
* Bengali-script support
* Grammar explanations
* Tense and verb rules
* Pronouns and possessives
* Classifiers and counting systems

### Culture and Heritage

Borok goes beyond vocabulary and grammar.

The platform also includes educational material covering:

* Kokborok's linguistic background
* Language classification
* Dialect communities
* Scripts
* Cultural context
* Heritage
* Historical information

## Learning Approach

Borok follows a simple learning cycle:

```text
Learn
  ↓
Understand
  ↓
Listen
  ↓
Practice
  ↓
Review
  ↓
Repeat
```

The goal is not simply to memorise Kokborok words, but to help learners understand how those words are used.

---

## Language Support

The learning experience currently provides:

* Kokborok
* English
* Bengali

Bengali is included as a bridge language because of its importance in the multilingual environment of Tripura.

---

## Content and Sources

The educational content is based on available linguistic and cultural reference materials, including government and academic resources related to Kokborok.

Because language is deeply connected to community and everyday usage, native-speaker validation is an important part of the project's development.

The project aims to distinguish between:

* Documented linguistic information
* Educational simplifications
* Dialectal variation
* Everyday spoken usage

## Contributing

Kokborok is a community language, so community knowledge is essential to making Borok better.

Contributions are especially valuable for:

* Correcting vocabulary
* Improving translations
* Verifying grammar
* Checking pronunciation
* Documenting dialect differences
* Adding useful phrases
* Improving cultural information

If you are a Kokborok speaker, linguist, educator, or someone familiar with the language, your feedback can help make the platform more accurate and useful.

### Contribution workflow

```bash
git clone https://github.com/<your-username>/<repository>.git
cd <repository>

npm install
npm run dev
```

For contributions:

```bash
git checkout -b improve-kokborok-content

git add .
git commit -m "Improve Kokborok lesson content"

git push origin improve-kokborok-content
```

Then open a Pull Request.

## Project Philosophy

Borok is built around a simple idea:

> **Language learning should be accessible, contextual, and connected to the people who speak the language.**

This project is not intended to replace native speakers, teachers, or academic linguistic work.

It is an attempt to make existing knowledge easier to discover, understand, and practice digitally.
